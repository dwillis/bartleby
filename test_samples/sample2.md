# The History of Programming Languages

## Early Days (1940s-1950s)

The first programming languages emerged in the 1940s and 1950s. Assembly language provided a more human-readable alternative to machine code.

### FORTRAN (1957)
- First high-level programming language
- Designed for scientific computing
- Still used today in some scientific applications

## The 1960s-1970s

This era saw the birth of many influential languages:

- **COBOL** (1959): Business-oriented language
- **LISP** (1958): Pioneered functional programming
- **C** (1972): Systems programming language that influenced countless others

## Modern Era

Today's programming landscape includes:

1. Python - General purpose, emphasis on readability
2. JavaScript - Web development standard
3. Rust - Systems programming with memory safety
4. Go - Concurrent programming made simple

The evolution continues as new paradigms and requirements emerge.
